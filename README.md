# 🚀 AI Short Ad Maker - 10-30s Video Ad & Commercial Generator

**AI Short Ad Maker** is a full-featured AI-powered Short Ad & Video Commercial Creator platform built for e-commerce brands, content creators, and marketers. It transforms product photos (such as HP Laptops, 4K Cameras, Smartphones, Skincare, Smartwatches) and custom prompts into high-energy 10-30 second video ads with Google Gemini AI enhancement.

---

| Technology / Library | Purpose in Project |
| :--- | :--- |

| **Person Safety Engine** | Enforces policy that person photos are ONLY used for product transformation/testimonial stories. |

| **LocalStorage State** | Persists generated video ads, user credit balances, and OTP login state. |

## ✨ Key Features & Functionality

### 1. 🤖 Google Gemini AI Prompt & Scenario Enhancer
- Turn simple inputs (e.g. *"make an ad on this image that I uploaded an HP laptop like this one"*) into a 10s-30s video edit scenario.
- AI suggested scenario prompt pills for HP Laptop, 4K Vlog Camera, Product Transformations, TikTok Hooks, and 50% Flash Sales.

### 2. 🛡️ Person Safety & Transformation Policy Verification
- **Safety Policy**: If a photo of a person is uploaded, ads are ONLY generated if the user confirms a genuine product transformation/testimonial story (e.g. *"This person changed after using our product"*).
- Trolling, roasting, or pranks on friends are strictly blocked with automated policy detection.

### 3. 🎬 10s, 15s (Free) to 20s, 30s (Pro) Ad Edit Tiers
- **10-Second & 15-Second Video Ads**: **100% FREE** fast video edits optimized for TikTok & Instagram Reels.
- **20-Second & 30-Second Video Ads**: Exclusive to **Pro Plan** members for deep product story breakdowns & customer testimonials.

### 4. 🛍️ Expanded Worldwide Product Asset Catalog
- Preset assets including HP Spectre AI Laptop, Sony Alpha 4K Camera, Active Noise-Canceling Headphones, Flagship OLED Smartphone, Smartwatches, Skincare Hydrating Serum, Gaming Keyboards, and more!

### 5. 🎙️ AI Vocal Engine (Hindi & Multi-Language Support)
- **Male & Female Voice Options**: Priya (Hindi Female), Rohan (Hindi Male), Sara (English Female), Alex (English Male), Camila (Spanish Female), and more.
- **Synchronized Subtitles & Multi-Scene Storyboard**: Words highlight dynamically in real time as the AI voice speaks!

## 💻 How to Run & Build

### 1. Start Node.js Express Backend Server (Nodemailer OTP Auth)
```bash
node server.js
```

### 2. Start Frontend Vite Dev Server
```bash
npm run dev
```
Open **[http://localhost:5173/](http://localhost:5173/)** in your browser.

### 3. Production Build & Linting Verification
```bash
npm run build
```
